# The Dreamer's Den

An unofficial, responsive fan hub for Shadow Slave readers. The site is a static page in `index.html`; it uses original discussion prompts and CSS illustrations, not official novel text or artwork.

## Publish with GitHub Pages

1. Create a **public** repository named `shadow-slave-vibecode` under `Aditya-kumar110`.
2. In the repository, open **Settings → Pages** and set the build/deployment source to **GitHub Actions**.
3. Push this repository's `main` branch:

   ```sh
   git remote add origin https://github.com/Aditya-kumar110/shadow-slave-vibecode.git
   git push -u origin main
   ```

The included workflow deploys the site on pushes to `main`. After its first successful run, the site should be available at:

<https://aditya-kumar110.github.io/shadow-slave-vibecode/>
